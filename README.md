# MAGverify

MAGverify assesses the integrity of metagenome assemblies and metagenome-assembled genomes (MAGs) using PacBio HiFi reads. Its ten modules cover read mapping, circularity, clipping, false closure, phantom sequences, repeats, taxonomic chimeras, false duplication, assembly variants and integrated QC.

## 1. Installation

MAGverify supports Linux with Conda or Mamba. Create the environment from the repository root:

```bash
git clone https://github.com/songmj86/MAGverify.git
cd MAGverify
mamba env create -f environment.yml
conda activate MAGverify
MAGverify doctor
MAGverify list
```

The environment includes anvi'o v9 and the command-line tools used by MAGverify. `MAGverify doctor` checks executable availability; it is not a full pipeline test. Detailed installation and environment verification are described in [Installation](docs/INSTALL.md). See [Recorded tool versions](docs/TOOL_VERSIONS.md) for software versions.

## 3. Database preparation

Taxonomic chimera analysis uses an MMseqs2 GTDB R232 protein taxonomy database (`--database`) or a gene taxonomy table (`--taxonomy`). MAG-level classification (`--mag-taxonomy`) is a separate input used for SCG annotation.

The MMseqs2 database uses three files from **GTDB R232**:

| Download | Content |
| --- | --- |
| [`gtdb_proteins_aa_reps_r232.tar.gz`](https://data.gtdb.ecogenomic.org/releases/release232/232.0/genomic_files_reps/gtdb_proteins_aa_reps_r232.tar.gz) | Predicted amino-acid sequences from GTDB representative genomes (~123 GB compressed) |
| [`bac120_taxonomy_r232.tsv`](https://data.gtdb.ecogenomic.org/releases/release232/232.0/bac120_taxonomy_r232.tsv) | Bacterial genome accession → full GTDB lineage |
| [`ar53_taxonomy_r232.tsv`](https://data.gtdb.ecogenomic.org/releases/release232/232.0/ar53_taxonomy_r232.tsv) | Archaeal genome accession → full GTDB lineage |

Detailed download commands, MMseqs2 DB construction, MAG taxonomy TSV format, existing GTDB-Tk result conversion and optional GTDB-Tk R232 classification are described in [Database preparation](docs/DATABASE_PREPARATION.md).

## 4. Run the analysis modules

Run each command separately in the following order, using the **same `--output-dir`** throughout. The examples use 100 threads; adjust this to the CPU allocation. The mapping manifest created in Step 1 is reused automatically by later modules. No `00_config.sh`, separate gene-taxonomy module or separate SCG module is needed. Detailed module prerequisites and outputs are described in [Module inputs and outputs](docs/MODULES.md).



## Input data

- **Assemblies** — A input folder of assembly FASTA files generated by multiple assemblers (.fa, .fasta or .fna), specified using `--contigs-dir`. Contig IDs must be unique across assembly files.
- **MAGs** — A input folder of MAG FASTA files (one file per MAG), specified using `--mag-dir`. MAG contig IDs must match those in the original assembly files.
- **Reads** — PacBio HiFi read files (.fastq or .fastq.gz), specified using `--reads` for read mapping. The mapping manifest records the read file, so later modules reuse it without `--reads`.
- **Output** — An output folder specified using `--output-dir`. Use the same folder across all modules to reuse completed results.

Detailed input specifications are described in [Input formats](docs/INPUT_FORMATS.md).





### 1. Read mapping

```bash
MAGverify map \
  --contigs-dir /path/to/assemblies \
  --reads /path/to/hifi.fastq.gz \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Maps PacBio HiFi reads separately to each original assembler FASTA, generating alignment evidence for downstream integrity assessments. The module writes the mapping manifest `01_mapping/mapping_manifest.tsv` (also linked as `results/mapping_manifest.tsv`), which lists each assembler FASTA, its HiFi BAM and the read file; later modules locate the BAMs and reads through this file.

### 2. Circularity

```bash
MAGverify circularity \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Evaluates read support for circular junctions to assess whether assembled contigs are circular.

### 3. Clipping

```bash
MAGverify clipping \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Detects clipping events and evaluates their support from HiFi read alignments. This and later modules reuse Step 1 mapping from the same output directory. If no mapping exists, supply `--reads` alongside the assemblies so mapping can be prepared.

### 4. False closure

```bash
MAGverify false-closure \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --assembler-circularity /path/to/assembler_circularity.tsv \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Identifies potential false circular closures by evaluating assembler circularity calls against read and clipping evidence. `--assembler-circularity` takes the assembler-reported circularity table, not the read-supported circularity result from Step 2.

### 5. Phantom sequences

```bash
MAGverify phantom \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Screens assembled sequences for regions lacking support from HiFi read coverage and raw-read k-mers.

### 6. Repeats

```bash
MAGverify repeats \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Identifies repetitive sequence regions and quantifies their extent across contigs and MAGs. Repeat detection and false-duplication testing are separate assessments.

### 7. Taxonomic chimera

```bash
MAGverify chimera \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --database /path/to/databases/GTDB_R232 \
  --mag-taxonomy /path/to/MAGverify_output/0_prep/MAG_taxonomy.tsv \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Screens for taxonomically inconsistent assembled sequences using gene-level taxonomy and HiFi read evidence. Use the MMseqs2 database prefix prepared as described in [Database preparation](docs/DATABASE_PREPARATION.md), or replace `--database PREFIX` with `--taxonomy /path/to/gene_taxonomy.tsv` when a compatible gene taxonomy table already exists. `--mag-taxonomy` is a separate MAG-level classification input. Gene taxonomy and SCG processing occur within this module as needed; chimera assessment also uses validated clipping results.

### 8. False duplication

```bash
MAGverify false-duplication \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Evaluates candidate false duplications using HiFi read mapping and clipping evidence.

### 9. Assembly variants

```bash
MAGverify variants \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Identifies assembly variants and evaluates read-level support for alternative alleles. This step may need substantial RAM; set `--memory-gb` when appropriate.

### 10. Integrated QC summary

```bash
MAGverify summary \
  --contigs-dir /path/to/assemblies \
  --mag-dir /path/to/MAGs \
  --output-dir /path/to/MAGverify_output \
  --threads 100
```

Integrates results from completed modules into a genome integrity summary and validates MAG IDs, contig memberships, counts and table consistency. Validation failures return a nonzero exit status. For a partial run, use `--include clipping,chimera` (or the modules completed). The summary does not rerun analysis modules.

## 5. Results

Final tables are linked under `OUTPUT_DIR/results/`; module directories retain the intermediate files.

| Module | Main output files |
| --- | --- |
| Read mapping | `mapping_manifest.tsv` |
| Circularity | `circularity_mag.tsv` |
| Clipping | `clipping_sites.tsv`, `clipping_contig.tsv`, `clipping_mag.tsv` |
| False closure | `false_closure_contig.tsv`, `false_closure_mag.tsv` |
| Phantom sequences | `phantom_contig.tsv`, `phantom_mag.tsv` |
| Repeats | `repeats_contig.tsv`, `repeats_mag.tsv` |
| Taxonomic chimera | `chimera_contig.tsv`, `chimera_mag.tsv` (plus gene taxonomy and SCG outputs when generated) |
| False duplication | `false_duplication_contig.tsv`, `false_duplication_mag.tsv` |
| Assembly variants | `variants_contig.tsv`, `variants_mag.tsv` |
| Integrated QC summary | `summary_contig.tsv`, `summary_mag.tsv` |

Keep the results directory and its module subdirectories together so the symbolic links remain valid.
